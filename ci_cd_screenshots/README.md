# CI/CD & Branch Protection Screenshots

Folder ini digunakan untuk menyimpan bukti screenshot penerapan CI/CD dan Branch Protection sesuai kriteria submission Dicoding:

1. **`1_ci_check_error.png`** (atau `.jpg`): Screenshot yang menunjukkan GitHub Actions CI check mengalami error karena salah satu pengujian gagal.
2. **`2_ci_check_pass.png`** (atau `.jpg`): Screenshot yang menunjukkan GitHub Actions CI check berhasil (all checks passed / centang hijau) setelah perbaikan.
3. **`3_branch_protection.png`** (atau `.jpg`): Screenshot yang menunjukkan aturan proteksi branch master/main aktif pada halaman Pull Request (misalnya: "Merging is blocked: At least 1 approving review is required" atau "Required status checks must pass").

> **Catatan:** Pastikan ketiga berkas screenshot di atas disertakan dalam berkas ZIP submission ke Dicoding.
